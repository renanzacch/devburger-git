# DevBurger

Projeto de cardápio interativo desenvolvido como exercício de JavaScript, praticando os métodos `forEach`, `map`, `reduce` e `filter`.

## Funcionalidades

- Exibir todos os lanches do cardápio.
- Aplicar 10% de desconto nos preços.
- Calcular a soma dos preços dos itens.
- Filtrar e exibir somente as opções veganas.
- Mostrar os preços formatados em reais (BRL).

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

Não é necessário instalar dependências. Clone ou baixe este repositório e abra o arquivo `index.html` em um navegador.

## Estrutura do projeto

```text
.
├── index.html
├── products.js
├── scripts.js
├── styles.css
└── img/
```

Os dados do cardápio estão em `products.js`, as funcionalidades em `scripts.js` e os estilos em `styles.css`.
